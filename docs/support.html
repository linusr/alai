Support

For help, bug reports or feature requests, open an issue on GitHub. Include your iOS version, the app version from Settings → About, and which server software you run.

Getting started

  1. Run the Alai server, which provides instant push.
  2. Open Alai, tap Connect Server, and enter the server address and your username and password or access token.
  3. Subscribe to topics from Browse Existing Topics or add a new one with +.
  4. Publish to a topic, for example curl -d "Hello" https://your.server/topic, and the message appears on your iPhone.

Common questions

Notifications only arrive when I open the app.
Instant push needs the Alai server with APNs enabled. Other ntfy-compatible servers are fetched while the app is open and during iOS background refresh. Settings → Servers shows the push status of each server.

The calendar doesn't show older days.
The calendar covers the period your server keeps messages for, which is set by its cache-duration.

A topic I expect isn't listed under Browse.
Browse shows topics you reserved, topics shared with your account, and topics synced from the web app. You can still add any topic by name with +.
